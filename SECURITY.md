# Security reports

Please report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Aethelgard-Systems/lookfirst/security/advisories/new).
If that route is unavailable, contact kontakt@aethelgard-systems.de. Do not open a public issue containing exploit details, credentials, personal data, or production logs.

Include the affected commit or version, Python and MCP client versions, transport and confirmation channel, a minimal reproduction with synthetic data, expected behavior, and observed impact. Remove credentials and identifying data before sending.

The latest public revision is the starting point for investigation. There is no guaranteed response or fix deadline, support commitment, or certification. Lookfirst reduces specific risks; it is not a sandbox. See the README's known limits and docs/threat-model.md.
